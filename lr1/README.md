### Задание
Проведение исследований с моделями **семантической сегментации**.

### 1. Выбор начальных условий

**Набор данных:** Oxford-IIIT Pet Dataset (бинарная семантическая сегментация: животное vs фон)

**Обоснование выбора:**  
Датасет содержит изображения кошек и собак с точной пиксельной разметкой. Задача сегментации домашних животных имеет реальное практическое применение: приложения для ветеринаров, приюты животных, умные пылесосы/роботы (чтобы не задеть питомца), фото- и видеоредакторы. Это классическая и востребованная задача в компьютерном зрении.

**Метрики качества:**
- **Dice Coefficient** (основная метрика)
- **mIoU** (mean Intersection over Union)
- **Pixel Accuracy**

Данные метрики являются стандартными для задач семантической сегментации и хорошо учитывают дисбаланс классов (фон занимает значительно большую площадь, чем объект).

### 2. Реализация

#### Baseline модели
- **UNet** с энкодером `resnet34` (pretrained on ImageNet)
- **DeepLabV3+** с энкодером `resnet34` (pretrained on ImageNet)

#### Улучшение бейзлайна
- Переход на более мощный энкодер — `efficientnet-b3`
- Добавлены аугментации данных (`HorizontalFlip`, `RandomBrightnessContrast`)
- Использован learning rate scheduler (`ReduceLROnPlateau`)
- Увеличено количество эпох обучения

#### Собственная имплементация
Реализована простая архитектура **U-Net** с нуля (без использования готовых библиотек для энкодера/декодера).

### Результаты

| Модель                              | Dice Coefficient |
|-------------------------------------|------------------|
| UNet (resnet34) — baseline          | 0.848            |
| DeepLabV3+ (resnet34)               | 0.890            |
| UNet + efficientnet-b3 (improved)   | **0.935**        |
| Собственная SimpleUNet              | 0.762            |

### Выводы

- Лучший результат показала улучшенная модель **UNet с энкодером efficientnet-b3** (Dice = 0.935).
- Гипотезы об использовании более сильного энкодера и планировщика скорости обучения полностью подтвердились — качество выросло существенно.
- Предобученные модели из `segmentation_models.pytorch` значительно превосходят собственную реализацию как по качеству, так и по скорости сходимости.
- Собственная имплементация U-Net показала приемлемый результат, но заметно уступает готовым решениям. Она полезна для понимания принципов работы архитектуры.

**Общий вывод:**  
Transfer learning и использование современных энкодеров сильно упрощают и улучшают решение задач семантической сегментации. В практических проектах рекомендуется начинать именно с предобученных моделей.
